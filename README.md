# Antarctic Treaty governance lineage

Code accompanying *Assessing Antarctic Treaty performance through the lineage of governance*, examining protected-area revisions and tourism requests to distinguish disagreement, later adoption, changes to provisions, maintenance of existing rules and legal effect. `tools/` contains summary builders and source-comparison scripts; `figures/` contains the current paper plotting code and editable infographic. Extracted data, coded request records, source locators and cached figure inputs will be deposited separately on Zenodo (dataset DOI: pending); extract that dataset into this directory, preserving its paths, and create the environment from `environment-analysis.yml`. Refresh the graph cache with `python tools/build_graph_profile.py --refresh` before running the plotting scripts because it records the builder source hash. Original-document checks additionally require the official sources referenced in the dataset, Pandoc and Poppler; these documents are not included in Git. The HTML infographic loads AntV from a CDN. This repository supports analysis from the released documentary graph and cached records, not reconstruction of the original OCR/model-assisted extraction pipeline. Documentary links include candidates and do not independently establish implementation or environmental effectiveness.
